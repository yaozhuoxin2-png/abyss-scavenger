# 深渊拾荒者 · Abyss Scavenger

单人俯视角动作地牢游戏，纯 HTML、CSS、JavaScript，无后端、无安装依赖。

## 在线游玩

[点击进入《深渊拾荒者》v8.2](https://yaozhuoxin2-png.github.io/abyss-scavenger/?v=8.2)

## 玩法

- 六层地下城；简单、中等、困难、地狱、炼狱难度每层分别包含 4 / 5 / 7 / 9 / 11 场普通战斗，之后再进入首领战。
- 长剑、猎弓、法杖三种起始职业；三者拥有独立的闪避、1 号和 2 号技能，分别偏向贴身斩击、多重射击和奥术控制。近战横扫拥有小幅伤害优势，远程箭矢与奥术范围爆炸保持原有定位。背包里的第二把武器可放入副武器栏，战斗中按 `3` 切换。
- 怪物随楼层按加速曲线成长，越深入生命与攻击提升越明显；第四、第五、第六层在原曲线之上再分别获得 ×2 / ×3 / ×4 的生命与攻击，第四层起每场还会固定出现深层精英。第六层最终 Boss 的最后三条镜像生命不吃这项额外倍率。敌人包括爬行怪、蛮兵、弓手、幽魂、裂壳怪、萨满、刺客和召唤者。
- 六名变形首领依次为裂壳巨兽、深渊骑士、星骸法王、血肉吞噬者、时空猎手和深渊模仿者。前三名拥有 2 / 3 / 4 条命，第四名开始均拥有 8 条命；每次复生都会变换外形、提高属性并切换技能，高阶段还会连续组合施法。
- 武器、胸甲、指环三个装备槽；普通、精良、稀有、史诗、黄金限定五种品质。装备品质越高，普通攻击的武器光芒、弹道、斩击、符文和命中特效越华丽。
- 升级所需经验会逐级提高；每次升级先获得攻击、生命、护甲、暴击、移速、法力上限和法力回复提升，但不再自动提高吸血，再从三项天赋中选择一项。
- 每场战后商店：四件不重复的精良以上装备，以及一件价值 300 金以上、属性极强且不会由怪物掉落的“黄金限定”装备。第一层起即可遇见只能购买且绝不掉落的至高装备；至高武器售价提高至 3200 金，防具与饰品仍为 1280 金。其他商品定价、装备价格和金币获取公式均保持不变。
- v3.1 开始“去棋子化”视觉重制：玩家使用四方向行走动画，基础敌人拥有完整身体和独立步行动作；角色只保留贴地接触阴影，不再绘制圆盘底座或头像式裁切。
- v3.2 将玩家生命体系放大 10 倍；Boss 伤害为原数值的 8 倍，小兵伤害按第 1–2、3–4、5–6 层分别放大 8、15、20 倍，敌人生命与玩家攻击不变。
- v4.0 新增独立主界面：开始游戏、难度选择、荣誉陈列与永久商城。简单难度保持此前版本数值；中等和困难提高敌人生命与伤害，并提供更高钻石结算倍率。
- 每场完整六层远征结束时，按推进深度、击杀、是否通关及难度结算钻石。钻石与荣誉永久保存在当前浏览器，可在主界面商城解锁额外药水、初始金币、法力容器和生命加成；该商城与局内烛火商会完全独立。
- 第六层首领的最后三条命会变成玩家镜像，实时复制玩家外形、当前武器、普攻和三项职业技能，不再使用原首领招式，也不会吸血。其生命与单次伤害在简单 / 中等 / 困难 / 地狱 / 炼狱难度分别为玩家的 3 / 8 / 18 / 28 / 45 倍，并拥有更快的移动与攻击节奏。
- 所有玩家吸血来源的最终效果统一降低 50%，装备和天赋界面显示削减后的实际吸血数值。
- v4.1 将主界面的四个入口统一为等宽等高的纵向菜单卡片，按“开始游戏、选择难度、查看荣誉、商城”的顺序从上到下排列。
- v4.2 大幅强化中等与困难难度：中等敌人生命 / 伤害为简单的 2.2 / 1.8 倍，困难为 4 / 3 倍；最终镜像分别提升至 8 倍和 18 倍。对应钻石结算倍率同步提高。
- v4.5 加固局外存档：每场战斗结束立即保存荣誉击杀和最深层数，主界面与侧栏显示自动保存状态；存储失败会明确报警，并支持 JSON 存档导出与确认后导入。简单与中等吸血在 v4.4 基础上提升至 2.5 倍，困难吸血保持不变。
- v4.6 法杖与猎弓改为地图内无限射程，只会被地牢墙体阻挡；空格键在没有锁定目标时朝鼠标方向自由射击。长剑的普攻与职业技能伤害整体提高 80%。
- v4.7 移除 Boss 受击时覆盖素材的白色矩形闪光，改为随 Boss 主题色变化的轮廓震光、双层冲击环、碎屑粒子与暴击符文。
- v5.0 新增实时 Canvas 首领击败 CG。前三层首领必定留下紫色史诗装备；第四、第五层神器分别用 `4` / `5` 主动释放，一局只能使用一次，效果为完全恢复生命与 5 秒无敌；第六层奖励可永久保存的王座碎片。碎片可在主界面重铸“最后的王座”，令后续远征全属性 +25%。本版本起每层普通战斗数固定调整为简单 4 场、中等 5 场、困难 7 场，与王座是否合成无关。
- 装备掉落会检查地面通行与玩家寻路结果；若落在墙体或封闭死角，会自动迁移到距离原掉落点最近的可到达地砖。局内“坚韧祝福”调整为 240 金，每次提高 200 最大生命并恢复等量生命。
- 主界面商城扩充至 36 件真实生效的永久升级，分为补给、体魄、武技、奥术、财富五类，并提供分类筛选。
- v4.4 将原货架奖励彻底重做为“第四圣约”：永久解锁武器、胸甲、指环之外的第四装备槽“遗物槽”。解锁后局内商店会出售十二种机制遗物，效果包括首领增伤、冷却缩减、击杀回蓝、药水强化、反伤、减伤、金币和掉率加成。

- v6.0 新增永久符文圣坛与主界面初始属性预览。六名首领各必掉一枚符文晶元，普通关卡有 0.35% 概率额外发现一枚；白 / 绿 / 蓝 / 金品质概率严格为 85% / 12% / 2.9% / 0.1%。白、绿符文强化单项初始属性，蓝、金符文全方位强化并附带星井回路、赤月回路、疾猎回路、王权圣痕、无尽秘仪或弑神律令等机制；最多装配六枚，存档后永久生效。

## 操作

| 按键 | 功能 |
| --- | --- |
| WASD / 方向键 | 移动，取消自动寻路和追击 |
| 鼠标左键点击地面 | 自动绕开墙壁走到目的地 |
| 鼠标左键点击敌人 | 自动追击并攻击 |
| 空格 / 按住鼠标右键 | 普通攻击 |
| Shift | 进入闪避瞄准，左键选择方向后释放；消耗 18 法力，冷却 4.2 秒，短暂无敌 |
| 1 / 2 | 进入职业技能瞄准，左键指定方向、目标或法术落点；分别消耗 32 / 45 法力，冷却 9 / 13 秒 |
| 3 | 切换主武器与副武器（需要先装备第二把武器） |
| 4 | 释放赤月生命圣器，立即恢复全部生命；每局一次 |
| 5 | 释放停滞神徽，获得 5 秒无敌；每局一次 |
| Q | 生命药水，恢复 50% 最大生命，冷却 3 秒；商店售价 59 金，药水格会按持有数量显示 |
| Z / X / C | 疾行 / 狂怒 / 守护药剂 |
| I | 背包，打开时暂停 |
| B | 战后商店 |
| E | 拾取附近装备 / 战后打开商店 |
| 鼠标右键 / Esc | 瞄准时取消施法；非瞄准状态下右键普攻、Esc 暂停或关闭菜单 |

走到发光传送门或使用商店的继续按钮进入下一场。靠近装备自动拾取。背包上限 40，满背包时物品留在地面；切换关卡前请留出空间。

## 运行和发布

GitHub Pages 从 `main` 分支根目录发布，不需要构建。所有资源使用相对地址，适配项目子路径。

本地需要 HTTP 服务（ES modules 不支持直接双击 `file://` 页面）：

```sh
node serve.mjs
```

打开终端输出的本地地址。按 Ctrl+C 关闭。可用 `node --experimental-vm-modules test.mjs` 运行地图、战斗及商店逻辑测试。

## 范围

朋友可通过网页地址直接进行各自的单人游戏，不含联机、账号、云存档、付费购买或手柄支持。当前远征只保存在内存，刷新页面会重置；钻石、荣誉、商城购买、王座与符文保存在当前浏览器。推荐桌面浏览器和键鼠。

所有游戏图形由原生 Canvas 绘制；音效由 Web Audio 合成，无第三方素材或远程运行依赖。
