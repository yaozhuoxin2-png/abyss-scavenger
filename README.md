# 深渊拾荒者 · Abyss Scavenger

单人俯视角动作地牢游戏，纯 HTML、CSS、JavaScript，无后端、无安装依赖。

## 玩法

- 六层地下城，每层两场遭遇战和一场首领战，共十八场战斗。
- 长剑、猎弓、法杖三种起始职业；三者拥有独立的闪避、1 号和 2 号技能，分别偏向贴身斩击、多重射击和奥术控制。近战横扫拥有小幅伤害优势，远程箭矢与奥术范围爆炸保持原有定位。背包里的第二把武器可放入副武器栏，战斗中按 `3` 切换。
- 怪物随楼层按加速曲线成长，越深入生命与攻击提升越明显；第四层起每场还会固定出现深层精英。敌人包括爬行怪、蛮兵、弓手、幽魂、裂壳怪、萨满、刺客和召唤者。裂壳怪死亡会分裂，萨满会治疗同伴，召唤者会召唤幼体，刺客会突袭。
- 六名变形首领依次为裂壳巨兽、深渊骑士、星骸法王、血肉吞噬者、时空猎手和深渊模仿者。前三名拥有 2 / 3 / 4 条命，第四名开始均拥有 8 条命；每次复生都会变换外形、提高属性并切换技能，高阶段还会连续组合施法。
- 武器、胸甲、指环三个装备槽；普通、精良、稀有、史诗、黄金限定五种品质。装备品质越高，普通攻击的武器光芒、弹道、斩击、符文和命中特效越华丽。
- 升级所需经验会逐级提高；每次升级先获得攻击、生命、护甲、暴击、吸血、移速、法力上限和法力回复的全属性提升，再从三项天赋中选择一项。天赋包含奥术蓄能、溢能核心、血战本能、处决印记、绝境回响、炼金血脉、技能回响、荆棘外壳、猎手专注、不稳定核心、星火回流和灵魂收割。
- 每场战后商店：四件不重复的精良以上装备，以及一件价值 300 金以上、属性极强且不会由怪物掉落的“黄金限定”装备。第 4 层起追加一件售价固定为 1280 金、只能购买且绝不掉落的“至高”武器。其他商品定价、装备价格和金币获取公式均保持不变。
- v3.0 采用暗黑哥特像素角色与黑金炼金术视觉；小怪、玩家和六位 Boss 使用独立角色美术，武器品质越高，攻击光效越华丽。
- Boss 技能拥有不同实际判定：圆形陨石、扇形横斩、十字与平行直线、冲锋路径、裂口墙、腐血地雷二次弹幕、箭雨轨迹和星铸棱镜，不再只是换名称的圆形伤害。
- 战斗房间会在断碑回廊、荧苔花园、赤烬熔炉、禁书藏库、月蚀圣所和星穹观测台之间变化，使用不同石柱、货架和通道布局。
- 第一场战后可选择精英试炼：下一场前两只怪物生命增加 50%，赏金增加 50%，精英必掉稀有装备。
- 背包对比与换装；菜单暂停；后台失焦自动暂停；本机最佳纪录。

## 操作

| 按键 | 功能 |
| --- | --- |
| WASD / 方向键 | 移动，取消自动寻路和追击 |
| 鼠标左键点击地面 | 自动绕开墙壁走到目的地 |
| 鼠标左键点击敌人 | 自动追击并攻击 |
| 空格 / 按住鼠标右键 | 普通攻击 |
| Shift | 闪避，消耗 18 法力，冷却 4.2 秒，短暂无敌 |
| 1 / 2 | 三种职业各有专属技能，分别消耗 32 / 45 法力，冷却 9 / 13 秒 |
| 3 | 切换主武器与副武器（需要先装备第二把武器） |
| Q | 生命药水，恢复 50% 最大生命，冷却 3 秒；商店售价 59 金，药水格会按持有数量显示 |
| Z / X / C | 疾行 / 狂怒 / 守护药剂 |
| I | 背包，打开时暂停 |
| B | 战后商店 |
| E | 拾取附近装备 / 战后打开商店 |
| Esc | 暂停 / 关闭菜单 |

走到发光传送门或使用商店的继续按钮进入下一场。靠近装备自动拾取。背包上限 40，满背包时物品留在地面；切换关卡前请留出空间。

## 运行和发布

GitHub Pages 从 `main` 分支根目录发布，不需要构建。所有资源使用相对地址，适配项目子路径。

本地需要 HTTP 服务（ES modules 不支持直接双击 `file://` 页面）：

```sh
node serve.mjs
```

打开终端输出的本地地址。按 Ctrl+C 关闭。可用 `node --experimental-vm-modules test.mjs` 运行地图、战斗及商店逻辑测试。

## 范围

朋友可通过网页地址直接进行各自的单人游戏，不含联机、账号、云存档、付费购买或手柄支持。当前远征只保存在内存，刷新页面会重置；最高纪录存在当前浏览器。推荐桌面浏览器和键鼠。

所有游戏图形由原生 Canvas 绘制；音效由 Web Audio 合成，无第三方素材或远程运行依赖。
